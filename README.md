# 🛍️ Sri Krishna Store – Django E-commerce Project

Hello 👋  
This is my Django-based e-commerce project.

It includes:

- 🛒 Add to Cart
- 📦 Checkout System
- 💳 Manual Payment Upload
- 👕 Product Size Variants (Small / Medium / Large)
- 👤 User Login & Signup
- 🧾 Order History
- 🛠️ Admin Panel

---

# 🚀 How To Run This Project (Step-by-Step)

Don't worry 🙂 Just follow these steps slowly.

---

## ✅ Step 1: Download The Project

Click the green **Code** button on GitHub  
Click **Download ZIP**

OR use this command:

# git clone <https://github.com/Monotosh13/myshop.git>

Then go inside the project folder:



# cd your-project-folder-name

---

## ✅ Step 2: Create Virtual Environment

Run this:

python -m venv venv


Now activate it:

### 👉 If you are using Linux / Mac:

source venv/bin/activate


### 👉 If you are using Windows:

venv\Scripts\activate


If activated correctly, you will see `(venv)` in your terminal.

---

## ✅ Step 3: Install Requirements

Run this:

pip install -r requirements.txt


Wait until installation finishes.

---

## ✅ Step 4: Run The Server

Now type:

python manage.py runserver


You will see something like:

Starting development server at http://127.0.0.1:8000/


Open your browser and go to:

👉 http://127.0.0.1:8000/

🎉 The project is now running!

---

# 🔐 Admin Panel

To open admin panel:

Go to:

http://127.0.0.1:8000/admin/

Login using the superuser credentials provided.
